# 实验报告检查清单

**写作时即时自检 + 审校时系统排查。按使用场景分节，逐项打勾。**

---

## 一、写作阶段即时自检（预防性）

**核心原则：写的时候就对，不要指望审校来兜底。**

### 数值管线原则（铁律）

- [ ] 正文中每个数值都来自脚本输出的唯一来源（`params.tex` 或 `\newcommand`）
- [ ] 严禁手动输入任何计算结果数值
- [ ] 讲义给定的标准值、仪器参数等固定值，已在注释中标注来源

### 每插入一张图后

- [ ] 数据来源是什么？（脚本文件名，版本是否最新？）
- [ ] 图中所有数值是否与脚本输出一致？
- [ ] 如果是外部图片，来源是否已标注？版权是否清晰？
- [ ] **渲染检查（强制）**：转 PNG 用 ReadMediaFile 直接查看
  - [ ] 无乱码（`$`、换行、反斜杠 mathrm 原样显示）
  - [ ] 无重叠（参数框不压数据点/曲线）
  - [ ] 无截断（包括参数框边缘）
  - [ ] 标签清晰（缩小到报告页面宽度后仍可读）
  - [ ] 物理量符号与正文一致
  - [ ] 单位正确
- [ ] 图是否有编号？`\label{fig:xxx}` 是否已设置？
- [ ] 正文中是否用 `Figure~\ref{fig:xxx}` 引用了这张图？
- [ ] caption 是否完整描述了图的内容、数据来源、物理意义？
- [ ] caption 中的数值是否与图中实际显示的数值一致？

### 每写完一个数据段落/表格后

- [ ] 段落中每个数值是否来自脚本输出的唯一来源？
- [ ] 数值的四舍五入是否前后一致？
- [ ] 单位是否正确？是否全文统一？
- [ ] 不确定度是否有依据？估算方法是否在正文中说明？
- [ ] 与标准值的对比是否引用了权威来源？
- [ ] 表格数值与正文数值是否完全一致？

### 每写完一个原理段落/公式后

- [ ] 每个公式是否有编号？是否在正文中被引用？
- [ ] 公式中的符号是否在首次出现时定义？
- [ ] 物理量符号是否与讲义一致？
- [ ] 推导步骤是否完整？有无跳跃？

### 每写完结论后

- [ ] 结论中的每个数值是否在前面正文/表格中出现过？
- [ ] 结论是否回应了实验目的？
- [ ] 结论是否有过度推断？（数据支撑是否充分）
- [ ] 结论中的偏差分析是否有物理依据？

### 实时维护两张表

**《数值来源表》**：
| 数值 | 来源文件 | 来源变量 | 使用位置 | 状态 |
|------|---------|---------|---------|------|

**《符号对照表》**：
| 物理量 | 报告符号 | 讲义符号 | 状态 |
|--------|---------|---------|------|

## 二、七维排查清单（粗筛）

### 1. 数据一致性（必须）
- [ ] 图中参数框内的拟合参数 ↔ 正文公式中的数值 完全一致
- [ ] 正文公式 ↔ 结果汇总表格中的数值 完全一致
- [ ] 标准值引用与最新权威数据源一致
- [ ] 样本量（事件数）在数据文件、正文、图表 caption 中一致
- [ ] **手写数据识别结果已多方验证**：若原始数据为手写记录，确认已用至少两种独立方法交叉验证，存疑之处已向用户确认

### 2. 讲义符合性（必须）
- [ ] 对照《实验要求清单》，逐项检查报告是否覆盖讲义所有要求
- [ ] 实验目的是否在报告中逐条回应
- [ ] 数据处理是否按讲义要求的步骤执行（分 bin、拟合模型等）
- [ ] 思考题是否全部回答，位置正确（正文/附录）
- [ ] 报告章节结构是否符合讲义要求
- [ ] **讲义未明确的数据处理方法，是否在报告中说明了选择理由？**
- [ ] **讲义未明确的误差分析维度，是否自行补充了合理的分析？**
- [ ] **是否有"过度扩展"（报告内容远超讲义要求，喧宾夺主）？**
- [ ] **仪器型号是否与讲义完全一致？（严禁自行推测通用型号）**
- [ ] **实验步骤细节（校准流程、样品参数）是否与讲义/实验记录一致？**

### 3. 措辞规范
- [ ] 科学用语准确，不口语化
- [ ] 语气客观，避免主观臆断（如"我觉得""可能大概"）
- [ ] 多组数据明确区分（自主测量 vs 参考/累计数据）
- [ ] 结论给出带不确定度的定量结果

### 4. 排版质量
- [ ] 编译无 error（允许少量 warning）
- [ ] 无 overfull hbox（文字溢出页边距）
- [ ] 页码、章节编号连续正确
- [ ] 图片宽度不超过页边距
- [ ] 表格不过宽
- [ ] **表格后无大片空白**：若单个表格占不满一页，考虑缩小字号、调整行距或与后续表格/文字合并同页
- [ ] **附录各节之间已分页**（`\clearpage`）

### 5. 图表质量
- [ ] 参数框/图例与任何数据点或拟合曲线无重叠
- [ ] 图中数学符号使用 LaTeX 格式
- [ ] 误差棒正确显示
- [ ] 数据图表输出为 300 DPI PNG，`bbox='tight'`
- [ ] 图表 caption 说明数据来源和物理意义
- [ ] **外部插入图片（如从 PDF/网页截图）内容完整，无截断、无缺失文字/标注**
- [ ] **从 PDF 提取的图片在白色背景下显示正常，无异常黑底/透明通道问题**
- [ ] **截图/提取的图片分辨率足够，文字和线条清晰可读**
- [ ] **原理图/示意图来自权威来源，禁止自行用 matplotlib/TikZ 绘制**
- [ ] **图与 caption 内容一致**：打开图片确认图中确实包含 caption 描述的部件、标注和物理量
- [ ] **图片物理量符号与正文一致**
- [ ] **外部图片已标注来源**，并在参考文献中列出完整引用
- [ ] **必须直接查看生成的图片文件**（转 PNG 用 ReadMediaFile 查看），不能仅通过 report PDF 的缩略图判断

### 6. 逐页检查
- [ ] 从封面到参考文献，逐页浏览 PDF
- [ ] 图表在 PDF 中清晰可读
- [ ] 公式编号与引用一致
- [ ] 交叉引用正确（`Figure~\ref{}` / `Table~\ref{}`）
- [ ] **所有插入图片在最终 PDF 中显示完整，无截断、无黑底、无模糊**

### 7. 参考文献
- [ ] 格式统一（`thebibliography` 环境）
- [ ] 期刊格式：`作者, ``标题,'' \textit{期刊} \textbf{卷}, 页码 (年份).`
- [ ] 外部图片来源在 caption 和参考文献中均已标注
- [ ] 标准值给出完整引用信息

## 三、深度审校：逐页逐图逐句检查（精筛）

**七维排查是粗筛，本检查是精筛。必须逐页、逐图、逐句执行，不能跳过。**

### 逐页检查（对每一页执行）

**结构完整性**
- [ ] 该页是否有页码？页码是否连续？
- [ ] 该页是否有章节标题？标题编号是否正确？
- [ ] 该页内容是否属于正确的章节？有无错页？

**内容完整性**
- [ ] 该页是否有空行过多或大片空白？
- [ ] 表格是否跨页断开？断开处是否有表头重复？
- [ ] 图片是否与正文在同一页或相邻页？

**排版细节**
- [ ] 有无 overfull/underfull 导致的文字挤压或稀疏？
- [ ] 公式是否完整显示？有无截断？
- [ ] footnote 是否在同一页底部？

### 逐图检查（对每一个图执行）

**来源与合法性**
- [ ] 数据来源是什么？（脚本文件名 / 外部来源）
- [ ] 如果是外部图，版权是否清晰？来源是否标注？
- [ ] 如果是数据图，脚本版本是否与当前报告一致？

**渲染质量（强制直接查看图片文件）**
- [ ] 用 ReadMediaFile 查看图片，确认无乱码
- [ ] 参数框/图例是否完整？有无截断？
- [ ] 坐标轴标签、刻度值是否清晰？
- [ ] 数据曲线是否完整？有无截断？
- [ ] 在报告页面宽度下缩小后是否仍清晰可读？

**与正文一致性**
- [ ] 图中数值与正文公式中的数值是否完全一致？
- [ ] 图中物理量符号与正文是否一致？
- [ ] 图中单位与正文是否一致？
- [ ] caption 描述是否与图中内容完全一致？
- [ ] 正文中引用该图的段落，描述是否与图一致？

**物理正确性**
- [ ] 坐标轴范围是否合理？有无异常截断？
- [ ] 数据趋势是否符合物理预期？
- [ ] 拟合曲线是否合理？有无过拟合或欠拟合？
- [ ] 误差棒是否正确表示？

### 逐句检查（对关键段落执行）

对以下段落必须逐句检查：
- **摘要**（每一句话都是浓缩信息，错误影响最大）
- **实验结论**（最可能被教师细读的部分）
- **数据处理方法和结果**（数值最密集的部分）
- **与标准值的对比分析**（偏差解释必须自洽）
- **思考题答案**（每句话都可能被挑错）

**逐句检查清单（对每一句话）**：
- [ ] 这句话中的每个数值，能否追溯到脚本输出的唯一来源？
- [ ] 这句话中的物理量符号是否与全文一致？
- [ ] 这句话的物理论断是否有数据支撑？
- [ ] 这句话是否存在过度推断？
- [ ] 这句话的单位是否正确？
- [ ] 这句话引用的是哪张图/哪个表？引用是否正确？
- [ ] 这句话是否有语法错误或歧义？

**高危表述审查**：

| 高危表述 | 风险 | 要求 |
|---------|------|------|
| "这说明..." | 过度推断 | 必须有直接数据支撑，否则改为"这可能与...有关" |
| "与理论值一致" | 模糊 | 必须给出偏差百分比和判断标准 |
| "误差很小" | 主观 | 必须量化，给出具体数值 |
| "如图X所示" | 引用错误 | 确认图X确实存在，且确实展示了所述内容 |
| "根据文献[3]" | 幽灵引用 | 确认正文中确实引用了文献[3] |

## 四、独立教师评审清单（阶段7.5）

**在完成上述检查后，启动独立评审 Agent。**

### 评审 Agent 必须执行的操作

1. [ ] 逐页浏览 PDF，确认排版和内容完整性
2. [ ] 每个图单独查看，确认渲染质量（无乱码/重叠/截断）
3. [ ] 逐句精读摘要和结论
4. [ ] 随机抽查几个数值，交叉验证一致性
5. [ ] 审查"说明""反映""证明"等强论断是否有数据支撑

### 评审重点

- [ ] **讲义硬性要求遗漏**：写作 Agent 自以为已覆盖，实际遗漏了某条要求
- [ ] **数据不自洽**：定标与反测结果矛盾、计算过程四舍五入导致不一致
- [ ] **物理不合理**：结果数量级错误、符号错误、违背基本物理规律
- [ ] **学术不严谨**：公式推导跳跃、误差分析无依据、引用与正文不匹配
- [ ] **定标自洽性未分析**：用标准样品定标后，是否反测验证了标准样品？
- [ ] **物理量符号混用**：讲义要求 $M_s$，报告却只给 $J_s$，未做换算或说明
- [ ] **图表渲染质量**：参数框有无乱码、有无重叠、有无截断
- [ ] **逐句过度推断**：结论中是否有数据无法支撑的强论断？

## 五、返工决策表

| 发现问题 | 回到阶段 | 说明 |
|---------|---------|------|
| 报告内容遗漏讲义要求 | 阶段1（需求理解） | 重新读讲义，更新《实验要求清单》 |
| 原始数据有问题 | 阶段2（数据审阅） | 检查数据源、格式、实验记录 |
| 数据处理结果异常或不符合讲义 | 阶段3（数据处理） | 重新选择/调整处理方法 |
| 图表质量问题 | 阶段4（可视化） | 改布局、改配色、重新输出 |
| 图片截断/黑底/模糊 | 阶段5（素材搜集） | 重新截取、换来源、处理透明通道 |
| 素材版权问题 | 阶段5（素材搜集） | 换来源、补标注 |
| 排版/格式问题 | 阶段6（报告撰写） | 改 LaTeX 源码 |
| 数据不一致 | 阶段2 或 3 | 核对原始数据源 |
| 数值管线断裂 | 阶段3 + 阶段6 | 重新统一数值来源 |

**返工后必须重新编译、重新校对。**

## 七、常见错误速查

| 症状 | 原因 | 修复 |
|------|------|------|
| 参数框压住数据点 | 参数框位置过低 | 调整 axes 坐标，确保底部高于数据 |
| 图中显示 `chi^2_nu` | 未用 LaTeX 命令 | 改为 `$\\chi^2_\\nu$` |
| 正文和图中数值不同 | 手动输入不一致 | 统一从拟合输出复制 |
| 编译报错 `Undefined control sequence` | 缺少宏包 | 检查是否加载 `amsmath` 等 |
| 图片模糊 | DPI 过低 | 设置 `savefig.dpi=300` |
| 图片有黑底 | PDF 提取的图片含透明通道 | 从 PDF 页面截图而非提取 embedded image |
| 截图截断文字/标注 | 截取区域过小 | 扩大截图范围，预览确认完整性 |
| 中文显示为方框 | 字体缺失 | 使用系统自带中文字体 |
| 遗漏讲义要求 | 未做需求理解阶段 | 回到阶段1，重新提取要求清单 |
| 图中参数框显示 `$J_s=...~\mathrm{emu}$$` 乱码 | matplotlib mathtext 中用了 `$$` + `\n` | 改为每行独立 `$...$`，用 `\n` 分隔 |
