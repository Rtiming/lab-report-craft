# 不确定时提问指南

## 核心规则

**遇到会改变实验事实、数据处理结论、讲义符合性或最终提交质量的不确定内容时，必须停下来向用户提问确认，提供选项供用户选择，严禁自行推测或编造。**

不确定性分两级处理：

| 级别 | 处理方式 | 示例 |
|------|----------|------|
| 阻塞级 | 停止相关处理，向用户提问 | 仪器型号冲突、手写数据无法确认、异常值处理、拟合模型会改变结论 |
| 偏好级 | 先采用合理默认方案，记录假设；必要时再问 | 图表布局、参数框位置、多个同等可靠图片来源 |

每个提问必须：
1. 清楚说明**为什么需要提问**（发现了什么问题）
2. 提供**2-4个明确的选项**
3. 给出**推荐的选项**（基于物理合理性）
4. 允许用户选择"其他"并提供自定义输入

---

## 各阶段提问触发点

### 阶段1：需求理解

#### 触发点 1.1 — 讲义未明确数据处理方法
**场景**：讲义只说"进行分析""处理数据"，未指定具体方法。

**提问模板**：
```
实验讲义未明确数据处理方法。讲义原文："[引用原文]"

当前数据特点：[简要描述，如"时间衰减数据，约300个数据点"]

请选择合适的处理方法：
A. [方法1，如"单指数拟合下降沿"]
B. [方法2，如"双指数拟合（快成分+慢成分）"]
C. [方法3，如"直接读取仪器输出的时间常数"]
D. 其他（请说明）

推荐：A（基于[物理理由]）
```

#### 触发点 1.2 — 讲义未明确仪器型号
**场景**：讲义提到了仪器名称但未给型号，或型号在讲义中不明确。

**提问模板**：
```
实验讲义中提到的仪器信息如下：
- 讲义原文："[引用原文]"

为了准确填写报告中的仪器表格，请确认：

您实际使用的仪器型号是？
A. [型号1，如"TH2851精密射频阻抗分析仪"]
B. [型号2，如"Keysight E4980A"]
C. 其他（请填写具体型号）

如果讲义中已明确列出型号，请直接告知具体型号。
```

#### 触发点 1.3 — 讲义文字有歧义
**场景**：讲义中某句话可以理解成两种意思。

**提问模板**：
```
讲义中以下内容有两种可能的理解：

讲义原文："[引用原文]"

理解A：[解释A]
理解B：[解释B]

请问您的理解是？
A. 理解A
B. 理解B
C. 其他（请说明）
```

### 阶段2：数据审阅

#### 触发点 2.1 — 数据格式无法自动识别
**场景**：数据文件格式不常见，无法确定列的含义。

**提问模板**：
```
数据文件 [文件名] 的格式无法自动识别。前5行内容：

[显示前5行]

请确认：
A. 第X列是[物理量1]，第Y列是[物理量2]
B. 数据格式是[格式描述]
C. 需要跳过前N行表头
D. 其他（请说明）
```

#### 触发点 2.2 — 发现异常值
**场景**：数据中出现负值、超量程值、极端异常值。

**提问模板**：
```
在数据审阅中发现以下异常：

[具体描述，如"第23行的时间值为 -5.2 ns，其余均为正值"]

请确认如何处理：
A. 剔除该数据点（视为坏点）
B. 保留但标注为异常
C. 检查原始实验记录是否有误
D. 其他（请说明）

推荐：A（负时间无物理意义）
```

#### 触发点 2.3 — 数据量与讲义描述不符
**场景**：讲义说"测量10组数据"，实际只有8组。

**提问模板**：
```
数据量检查发现问题：
- 讲义要求：[描述，如"每组测量3次，共10组"]
- 实际数据：[描述，如"只找到8组数据"]

请确认：
A. 数据缺失，需要补充测量
B. 部分数据保存在其他文件中
C. 实际实验时未按要求完成全部测量
D. 其他（请说明）
```

---

### 阶段3：数据处理

#### 触发点 3.1 — 拟合模型不确定
**场景**：数据可以用多种物理模型拟合，讲义未指定。

**提问模板**：
```
当前数据可用多种模型拟合，讲义未指定具体模型：

数据特点：[描述]

候选模型：
A. [模型1，如"单指数衰减 N(t) = A·exp(-t/τ) + C"]
B. [模型2，如"双指数衰减 N(t) = A₁·exp(-t/τ₁) + A₂·exp(-t/τ₂) + C"]
C. [模型3，如"多项式拟合"]
D. 其他（请说明）

推荐：A（基于[物理理由]）
```

#### 触发点 3.2 — 拟合结果异常
**场景**：拟合得到非物理结果（如负寿命、发散）。

**提问模板**：
```
拟合结果出现异常：

拟合参数：[显示异常参数]
物理预期：[描述预期范围]

可能原因：
A. 初值设置不当
B. 本底项缺失
C. 数据范围选择不当
D. 模型不适用

请确认如何处理：
A. 调整初值重新拟合
B. 增加本底项重新拟合
C. 截断数据范围重新拟合
D. 换用其他模型
E. 其他（请说明）
```

---

### 阶段4：可视化

#### 触发点 4.1 — 图表类型不确定
**场景**：讲义未指定图表类型，数据特点支持多种展示方式，且不同图表会影响报告结论或读者判断。

若只是布局偏好且不影响结论，默认选择最清晰方案并在记录中说明理由。

**提问模板**：
```
当前数据支持多种图表展示方式：

数据特点：[描述，如"3组不同电压下的C-V曲线"]

图表选项：
A. 多子图（3×1，每组一个子图）
B. 重叠曲线（全部画在一张图上，不同颜色区分）
C. 两者都做
D. 其他（请说明）

推荐：A（对比清晰，避免线条过多重叠）
```

#### 触发点 4.2 — 参数框位置不确定
**场景**：自动避障后仍无法确定参数框位置是否遮挡关键信息。

**提问模板**：
```
当前图表的数据分布较广，参数框默认位置（右上角）可能与数据重叠。

请确认参数框位置：
A. 右上角（默认）
B. 左上角
C. 右下角
D. 放在图外（使用bbox_to_anchor）
E. 不放参数框（仅在正文中给出参数）
```

---

### 阶段5：素材搜集

#### 触发点 5.1 — 原理图来源不确定
**场景**：讲义中有原理图但来源不明，或需要替换示意图。

**提问模板**：
```
实验报告需要插入原理示意图。讲义中的图：[描述]

请确认图片来源：
A. 使用讲义中的图（如有电子版）
B. 从权威机构网站搜索（Fermilab/CERN/PhET等）
C. 用户自行提供图片
D. 不插入原理图，仅用文字描述
```

---

### 阶段6：报告撰写

#### 触发点 6.1 — 仪器型号与讲义不一致
**场景**：讲义写TH2851，但实际使用的是其他型号。

**提问模板**：
```
发现报告中的仪器型号与讲义不一致：

- 讲义中写的型号：[型号A]
- 实际使用的型号：[型号B]（或无法确认）

请确认报告中应写哪个型号：
A. 以讲义为准：[型号A]
B. 以实际使用为准：[型号B]
C. 两者都写（讲义型号+实际型号注释）
D. 其他（请说明）

推荐：B（报告应反映实际实验）
```

#### 触发点 6.2 — 样品参数不确定
**场景**：样品尺寸、型号等参数在讲义和实验记录中不一致。

**提问模板**：
```
样品参数存在不确定性：

- 讲义中写的参数：[值A]
- 实验记录中的参数：[值B]
- 数据处理中使用的参数：[值C]

请确认报告中应使用哪个值：
A. [值A]（讲义）
B. [值B]（实验记录）
C. [值C]（数据处理实际使用）
D. 其他（请说明）
```

---

### 阶段7：校对迭代

#### 触发点 7.1 — 数据不一致
**场景**：图中参数框、正文公式、汇总表三处数值不一致。

**提问模板**：
```
数据一致性检查发现问题：

- 图[图号]参数框中的值：[值A]
- 正文公式中的值：[值B]
- 表[表号]中的值：[值C]

请确认以哪个为准：
A. 以图为准（[值A]）
B. 以正文公式为准（[值B]）
C. 以表格为准（[值C]）
D. 重新计算核实

推荐：D（数据源头应唯一）
```

#### 触发点 7.2 — 发现与讲义要求不符
**场景**：校对时发现报告遗漏了讲义的某项要求。

**提问模板**：
```
讲义符合性检查发现问题：

- 讲义要求：[具体要求]
- 当前报告状态：[未包含/部分包含]

请确认如何处理：
A. 补充相关内容
B. 讲义要求不适用于本次实验（请说明理由）
C. 其他（请说明）
```

## 禁止行为清单

以下情况**严禁自行决定**，必须提问：

- [ ] 仪器型号与讲义不一致时，自行选择其中一个
- [ ] 讲义未明确数据处理方法时，自行选择一种方法而不告知用户
- [ ] 数据出现异常值时，自行剔除而不告知用户
- [ ] 样品参数在多个来源不一致时，自行选择一个值
- [ ] 图表类型会影响结论表达时，自行决定一种布局
- [ ] 发现数据不一致时，自行修改其中一个而不核实
- [ ] 任何与实验讲义有出入的地方，自行决定以哪个为准
